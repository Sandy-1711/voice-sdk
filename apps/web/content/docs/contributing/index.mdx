## Repository layout

```
packages/core       @swungstudent/voice — the shared interface
packages/test-kit   fake servers and shared contract assertions
packages/internal   helpers shared between providers, not published
providers/*         one package per provider
examples/*          runnable programs, typechecked in CI
apps/web            this site
docs/               design notes
```

## Provider package structure

Every provider package uses the same file layout, one file per concern:

```
src/
├── config.ts        API key, defaults, and option resolution
├── format.ts        AudioFormat translation
├── tts.ts           speak() and speakStream()
├── tts-session.ts   openTTSSession()
├── stt.ts           transcribe()
├── stt-session.ts   openSTTSession()
├── provider.ts      the VoiceProvider implementation
└── index.ts         public exports
```

`provider.ts` should contain little more than delegation to the other modules.
